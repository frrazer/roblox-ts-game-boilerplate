# Frazer's Game Boilerplate (roblox-ts)

The roblox-ts version of my game boilerplate: Flamework, React, Charm, ProfileStore and Conch, set up so AI agents build Roblox games the right way.

Ask your agent to set up the boilerplate by running the install steps, and the rest is easy!

```powershell
rokit install
npm install
npm run watch
npm run serve
```

<details>
<summary>For AI agents:</summary>

If you're an agent, please refer to [AGENTS.md](/AGENTS.md) before making any code changes or running install steps.

</details>
